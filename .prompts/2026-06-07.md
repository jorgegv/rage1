### Plan (draft — pending user approval; do NOT code until approved)

**Decision (user-chosen, 2026-06-07):** per-game build dir under `build/<game>/`,
isolated by REFLINK-COPYING the tree there and running the UNMODIFIED build
confined to it via `make -C build/<game>`. No git dependency. Default
`make build` stays on plain `build/`; only `all-test*` opt into split dirs.
Chosen over a true out-of-tree object-path refactor to keep changes minimal and
output byte-identical by construction.

**Shared-state map (why parallel builds collide today):**
1. In-tree object writes: `engine/src|lowmem|banked_code/**/*.o`, `banked_code.bin/.map`,
   AND `external/jsp/lib/**/*.o` (JSP compiles next to its sources). → fixed by per-game tree copy.
2. Repo-root artifacts: `main.bin`, `main.map`, `game.tap`, `screen.tap`,
   `bank_*.tap`, `sub_*.tap`, `asmloader.tap`, CPC `game.{cpc,dsk,cdt}`. → land inside build/<game>/.
3. Shared `build/` dir (already `$(BUILD_DIR)` var) → becomes build/<game>/build/.

**Mechanism:** plain `cp -a` (modern coreutils defaults to `--reflink=auto`, so
it CoW-snapshots on btrfs — near-instant, near-zero disk, no shared-inode
overwrite risk — and falls back to a normal copy off-btrfs, automatically).
Copyable subset ~16M (engine 2.7M + jsp 6.6M + tools/lib/etc/games).

**Plan:**
- Branch `parallel_regression_tests` off refactor_for_multiplatform.
- Generic `test-build-split-%`: rm+mkdir build/$*, `cp -a` tree (auto-reflink), then
  `make -C build/$* build-$*` (reuses each game's existing platform-correct
  target), log to build/$*/build.log, scrape verdict from log.
- Parameterize the ONE inner `-j8` literal (Makefile-zx48/zx128) → `-j$(BUILD_JOBS)`
  (default 8) so nested concurrency is tunable.
- Dispatcher target depending on all split targets, run `make -j$(MAX_PARALLEL_JOBS)`
  (default 4, CLI override). Rewire all-test-builds-zx/-cpc/all-test-builds to it,
  keeping check-input-* pre-steps + binary-safe per-subset Errors scrape.
  MAX_PARALLEL_JOBS=1 = serial fallback.
- Adding a game unchanged (drop games/<game>/ + build-<game>; auto-discovered).

**Gotchas on record (non-blocking):** (a) external/jsp in-tree .o → must be copied
(it is); (b) nested -j control via BUILD_JOBS = the only existing-recipe edit;
(c) manual post-build tools (mem, dsinfo.sh, r1size.sh, mem-summary-*) hardcode
plain `build/` — OUT OF SCOPE, conscious omission.

**Acceptance:** split-dir parallel all-test-builds = 18/18 (same as serial today)
+ artifact byte-identity spot-check vs in-place build + independent reviewer pre-merge.

**Resolved decisions (user, 2026-06-07):**
- Per-game root = `build/_tests/<game>/` (keeps top-level build/ clean; artifacts
  at build/_tests/<game>/game.tap | game.dsk).
- Inner `BUILD_JOBS` default = 4 on the parallel path (4 games × 4 ≈ 16 compilers);
  normal `make build` keeps -j8. Both knobs CLI-overridable.
- No separate serial target — ONE code path; serial = `make all-test-builds MAX_PARALLEL_JOBS=1`.
